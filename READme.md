# 8-bit ALU Design and Verification

## Project Overview
Designed an 8-bit Arithmetic Logic Unit (ALU) using SystemVerilog and verified its functionality using a self-checking testbench.

## Supported Operations
- Addition
- Subtraction
- Bitwise AND
- Bitwise OR
- Bitwise XOR
- Bitwise NOT
- Zero flag generation
- Invalid opcode handling

## Files
- `alu.sv` — RTL design
- `tb_alu.sv` — Self-checking testbench

## Verification
The testbench checks arithmetic operations, bitwise operations, overflow, subtraction wraparound, zero results, and invalid opcodes.
